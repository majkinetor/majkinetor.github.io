# Agent instructions

- Don't change, commit or push anything on your own. Propose the change first and wait for the owner to confirm it.
- Questions and discussion ("what about…", "we just talk now") are not requests to edit. Answer and wait.

**Read [`dev/agents/AGENTS.general.md`](dev/agents/AGENTS.general.md) first, every session.** It holds the owner's rules for any project, copied unchanged from his other repos; [`dev/agents/STANDARDS.general.md`](dev/agents/STANDARDS.general.md) has the numbered standards they link to. This file wins where the two differ, so the two rules above stand over anything there that allows acting alone.

## This repo

- The owner's personal site, [milic.info](https://milic.info), built by GitHub Pages with Jekyll from `docs/`. How it's put together is in [README.md](README.md).
- **`main` is the live site**: a push to it is published in about a minute. Everything outside `docs/` is not published.
