Projects: ten timeline prototypes

All ten read the same projects.json and link to the same project page. Pick a direction, then we'll turn it into the real page.

  1. 01Transit mapEach project is a subway line, each start a station. Dashed track means development, solid means production.
  2. 02git log --graphThe career as a commit graph. Branches are projects, tags mark go-live, flags filter.
  3. 03EditorialMagazine layout with giant outlined years and hairline threads. Featured work is set large, the rest stays one line.
  4. 04Swimlanes by companyTrue-scale vertical Gantt chart, one column per company that carried the work.
  5. 05htopA process table with meters and a load histogram. Keyboard driven: j/k, Enter, F3, F4, F6.
  6. 06BlueprintAn engineering drawing at true scale, with leader-line labels and a title block for the stats.
  7. 07RFC 2026A plain-text RFC with an ASCII lane graph. Nothing a 1990 terminal could not print.
  8. 08Spacecurve26 years folded into a Hilbert curve, then one chapter per year with a slice of the river of parallel work.
  9. 09Logic analyzerChannels are lanes, a high signal is a running project, a clock is development, decoder boxes carry the names.
  10. 10NotebookEditable query cells over the JSON, like an interactive tutorial. The timeline is one of the outputs.

Plain HTML, CSS and one 200-line script. No build step and no framework.
